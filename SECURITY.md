# Security Policy

Report a vulnerability in this template, or in the extensions it generates, privately: open the
repository's [Security tab](https://github.com/smarter-sh/smarter-extension-cookiecutter/security)
and choose **Report a vulnerability**. Please do not use public issues, discussions or pull
requests. A vulnerability in the Smarter platform itself goes to
[smarter-sh/smarter](https://github.com/smarter-sh/smarter/security).
